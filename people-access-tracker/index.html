Manager exits are a different process, and the hard part is 2FA. Their phone is the second factor on accounts the company owns — Meta Business Manager, Google Ads, Mercury, the Workspace super-admin role. Rotating the password doesn't help: the moment they hand back the login you're locked out behind a code only their device can produce.

The rotation, when a creative leaves

  1. Rafael changes the creatives@adpros.com password.
  2. Check each tool below still signs in — some send a re-verification email to the shared inbox.
  3. Redistribute to the creatives who remain.
  4. Anything the leaver set up with 2FA on their own phone needs transferring before their last day. Same rule as the manager path.

Using this

  1. Someone accepts an offer → Intake email tab. Send the request for contract and payment details the same day.
  2. Details come back → Onboarding tab, pick their role, work the list top to bottom.
  3. Someone resigns or is let go → Offboarding tab. Tick the manager box if they hold admin rights anywhere, and do the purple block before their last day.
  4. Creative departure → also rotate creatives@adpros.com.
  5. Monthly → check the tool inventory against the Mercury export.
