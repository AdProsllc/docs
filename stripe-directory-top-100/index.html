    03 How it was built

    Method

    Pipeline

    Swept Stripe Directory (CLI) filtered to countries-supported = US + CA across 74 D2C keywords → 877 unique opt-in profiles. Ranked by product-fit signals, resolved the obfuscated stri.pe links to real domains, then ran a strict classification pass that removed services, clinics, SaaS, marketplaces, wholesalers and breeders — keeping genuine DTC product brands. Top 100 selected, US/CA first.

    Enrichment level

    “Medium”: resolved website + vertical + region + subscription likelihood + ad-fit + one-line note. Next level adds contact emails (for outreach), live ad-library activity (who’s actively running Meta/Google ads = hotter), and Shopify / subscription-app detection.

    04 Read before acting

    Caveats

    Region is inferred

    HQ region is derived from domain, language and legal suffix, not verified. The 11 “Unknown” are probably US. Stripe’s filter is “supports US/CA,” so a brand can sell here but be based elsewhere — spot-check any that matter.

    It’s a sample, not a census

    The directory is opt-in, so this is a slice of Stripe merchants, not all of them. Subscription & ad-fit are model judgments from short descriptions. Going wider means more keywords (each caps ~50 results), not more pages.
