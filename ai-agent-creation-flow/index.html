AI Agent Creation Flow

How a user creates an agent in the AI Ad Pros app using natural language

01 Overview

From prompt to live agent in one conversation

The user describes what they want in plain English. Claude parses the intent, drafts an agent config, and confirms six dimensions of scope — delivery first, analysis second. Once the user signs off, the agent goes live and runs on its schedule.

04 Why this order

Delivery first, depth last

Lightweight up front

Notifications, export, schedule, and frequency are binary or small-list decisions. The user can answer them in seconds without losing momentum.

Depth at the end

Ads library data and methodology are richer. Claude pre-fills both from the original prompt — the user just confirms or refines instead of being asked from scratch.

Edit loop, not a wizard

After the summary, the user can change any field by name in conversation. No "go back to step 3" — Claude addresses the config directly.

"Ship it" as the trigger

A single confirmation locks the agent live. The agent then runs on its schedule, exports in the chosen format, and notifies on the chosen channel.
